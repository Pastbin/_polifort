Проект представляет собой веб-приложение для компании, занимающейся металлообработкой. Основной стек технологий включает Laravel (PHP) для бэкенда и Vue 3 (TypeScript) для фронтенда. Сборка проекта осуществляется с помощью Vite, что обеспечивает высокую скорость разработки и оптимизированную сборку.

Основные технологии и библиотеки:
- Laravel: Используется для создания API, управления маршрутами, аутентификации и работы с базой данных. Laravel Sanctum обеспечивает безопасную аутентификацию через токены. Laravel был выбран за его удобство, встроенные инструменты для безопасности и поддержку MVC архитектуры. В сравнении с Python (например, Django), Laravel предлагает более простую и интуитивно понятную структуру для веб-приложений, а также более широкую поддержку сообщества.
- Vue 3: Фреймворк для создания реактивного и компонентного интерфейса. Использование TypeScript повышает надежность и читаемость кода. Vue был выбран вместо React из-за его простоты, меньшего объема кода и более легкой интеграции с существующими проектами. Vue также предлагает более гибкую и понятную систему реактивности.
- Vite: Инструмент для сборки фронтенда, обеспечивающий мгновенную перезагрузку страниц (HMR) и оптимизированную сборку. Vite был выбран вместо Webpack из-за его высокой скорости разработки и минимальной конфигурации. Vite использует нативные ES-модули, что делает его более производительным в сравнении с Webpack.
- Tailwind CSS: Используется для стилизации компонентов, что позволяет быстро создавать адаптивные интерфейсы. Tailwind был выбран за его гибкость и возможность кастомизации, что упрощает создание уникального дизайна.
- Inertia.js: Связывает фронтенд и бэкенд, позволяя создавать SPA (Single Page Application) без необходимости написания отдельного API. Inertia.js был выбран за его простоту и возможность использования одного кодового базы для фронтенда и бэкенда.

Безопасность:
- Аутентификация реализована через Laravel Sanctum, что обеспечивает безопасное управление сессиями и токенами. Sanctum был выбран за его простоту и возможность использования как для SPA, так и для мобильных приложений.
- Все данные валидируются на стороне сервера, а также используются CSRF-токены для защиты от межсайтовой подделки запросов.
- Пароли хранятся в хэшированном виде с использованием алгоритма bcrypt.

Оптимизация:
- Изображения оптимизированы с помощью библиотеки Sharp, что уменьшает их размер без потери качества. Sharp был выбран за его высокую производительность и поддержку множества форматов изображений.
- Используется ленивая загрузка изображений для повышения скорости загрузки страниц.
- Формат изображений заменен на WebP для уменьшения размера файлов.

База данных:
- В качестве базы данных используется SQLite, что упрощает разработку и тестирование. SQLite был выбран за его простоту и отсутствие необходимости в отдельном сервере базы данных.
- Миграции и сидеры позволяют легко управлять структурой базы данных и начальными данными.

Автоматизация:
- Развертывание на сервер автоматизировано с помощью скрипта на Node.js, который использует библиотеку ftp-deploy. FTP был выбран за его простоту и широкую поддержку на большинстве хостингов.
- Для тестирования используется Pest, что позволяет быстро находить и исправлять ошибки. Pest был выбран за его простоту и интеграцию с Laravel.

SEO и доступность:
- Проект оптимизирован для поисковых систем, включая использование мета-тегов и семантической разметки.
- Адаптивный дизайн обеспечивает корректное отображение на всех устройствах.

Возможные вопросы:
1. Почему был выбран Laravel?
   Laravel был выбран за его удобство, встроенные инструменты для безопасности и поддержку MVC архитектуры. В сравнении с Python (Django), Laravel предлагает более простую и интуитивно понятную структуру для веб-приложений.
2. Почему был выбран Vue, а не React?
   Vue был выбран за его простоту, меньший объем кода и более легкую интеграцию с существующими проектами. Vue также предлагает более гибкую и понятную систему реактивности.
3. Почему используется Vite, а не Webpack?
   Vite был выбран за его высокую скорость разработки и минимальную конфигурацию. Vite использует нативные ES-модули, что делает его более производительным в сравнении с Webpack.
4. Как реализована аутентификация?
   Аутентификация реализована через Laravel Sanctum, который использует токены для управления сессиями.
5. Какие меры безопасности применяются?
   Используются CSRF-токены, валидация данных на сервере, хэширование паролей и защита от SQL-инъекций.
6. Как оптимизирована загрузка страниц?
   Используется ленивая загрузка изображений, оптимизация форматов и минификация CSS/JS.
7. Как происходит развертывание на сервер?
   Развертывание автоматизировано с помощью скрипта на Node.js, который загружает файлы через FTP.
